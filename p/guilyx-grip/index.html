Grip documents a diff-explanation quiz, an optional Git pre-push hook and coding-agent integrations. A model grades the developer's explanation of a change; the score does not certify code correctness or security.

When to use this reference

Compare workflows for discussing and explaining a diff before pushing it. Check which provider receives code changes and answers, and how the hook is enabled or bypassed.
